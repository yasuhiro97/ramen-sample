# 輸入事後調査資料 作成ツール

輸入許可通知書(PDF)から、管理番号の採番・輸入明細一覧(Excel)への追記・表紙(Excel)の作成を行う。
ルール: 「輸入事後調査資料作成について(2026年3月)」(81期以降)。

## 準備
    pip install -r requirements.txt

## ダブルクリックで使う(月1回の運用向け)
`run.bat` をダブルクリック → フォルダ選択 → 事業所名 → 種別を選ぶ → 内容を確認して保存。
保存後に出力フォルダが開く。事業所名と前回のフォルダは `settings.json` に記憶される。

## コマンドで使う
    # 海外送金あり(管理番号 81-001, 81-002 ...)
    python import_audit.py 許可通知書.pdf --office "林六／東京"
    # 海外送金なし(管理番号 経81-001 ... 別体系)。種別: 着払 / 無償 / 乙仲
    python import_audit.py 許可通知書.pdf --nosend 着払 --office "林六／東京"
    # フォルダ内のPDFをまとめて
    python import_audit.py ./許可通知書フォルダ --office "林六／東京"

出力先: デスクトップ/輸入事後調査/第81期/ (`--out` で変更可)
- `輸入明細一覧_81期.xlsx` … 「海外送金あり」「海外送金なし」シート。申告番号・仕出人・許可年月日・管理番号・事業所名を自動入力
- `表紙/表紙_<管理番号>.xlsx` … 申告番号・仕出人・許可年月日・管理番号を入力済み

自動入力しない項目(送金日・金額・乙仲業者名・チェック欄など)は Excel で手入力する。
同じ申告番号は二重登録しない。

## スキャンPDF(OCR)
文字情報のない PDF は自動で OCR(RapidOCR、追加ソフト不要)にかける。フォルダを指定すると、下位フォルダの PDF もすべて対象。
OCR で崩れた仕出人名は、`輸入事後調査/仕入先名.txt`(1行1社)と既存台帳の仕入先名に照合して補正する。
照合できなかった仕出人は台帳で黄色にするので確認する。

## ルール: 同月の同じ仕出人は管理番号をまとめる
`import_audit.py` の `MERGE_MONTHLY` に書いた仕出人(初期値: TAEKWANG INDUSTRIAL CO.,LTD.)は、輸入許可日が同じ月なら同じ管理番号にする。
台帳は申告番号ごとに1行、表紙は管理番号ごとに1枚(申告番号欄に追記)。

## 送金計算書の読み取り(海外送金あり)
同じフォルダ(下位フォルダ含む)に、銀行の「送金計算書」PDFがあれば、次を自動で読み取る。
- 送金計算書: 送金日・通貨・外貨額・レート・円貨額・受取人
- 許可通知書: 仕入書価格(通貨・金額)・数量・品名
許可通知書の仕入書価格の合計が送金額に一致するものを「同じ送金」とみなし、同じ管理番号にする。
台帳の 送金日/送金通貨/送金額/数量/単位/単価/仕入金額(円)/商品名 を入れ、表紙の送金額欄も埋める。
合わない・読めない欄は黄色。商品名の変換表は `輸入事後調査/商品名.txt`(ENGLISH=日本語)。
